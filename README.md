# Polymorphism in C++
This repository consists basic C++ code covering the core idea of **Polymorphism** along with it's uses, types and properties. 

## Purpose
This repository is created for learning, understanding and practicing basic Polymorphism.

### Concepts covered
- Static Polymorphism
- Dynamic Polymorphism
- Pure virtual function
- Virtual Destructor
- Abstract/ Concrete class

## How to Run

### Compile<br>
    - g++ static_polymorphism.cpp ~o static_polymorphism

### Run
    - ./static_polymorphism
- Replace the file name for whichever program you want to run.
